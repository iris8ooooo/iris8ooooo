# 애플워치 설계 (M7 / v1.1 후보)

작성 2026-09-13. **아직 구현 안 함 — 오너 결정 대기.**

## 왜 하는가

현장에서 폰을 꺼내기 어렵다. 장갑, 분진, 안전모, 높은 곳. 손목에서 **한 번 톡 쳐서 오늘 1공수**가 들어가면 "퇴근하고 몰아서 적다가 빼먹는" 문제가 사라진다. 기록 누락은 곧 월급 증빙 누락이다.

경쟁앱 4강 중 애플워치를 지원하는 앱은 확인된 바 없다(스토어 페이지 직접 확인은 못 했고, 기능 소개·리뷰 조사 범위에서 언급 없음). 위젯에 이어 두 번째 하드웨어 차별화가 된다.

## 기술 제약 (조사 결과)

- **Flutter 는 watchOS 를 지원하지 않는다.** 워치 앱은 같은 Xcode 프로젝트 안의 **네이티브 SwiftUI watchOS 타깃**으로 만든다. 홈 위젯(`ios/GongsuWidget`)을 넣은 방식과 같다.
- **폰↔워치 통신은 App Group 이 아니라 `WatchConnectivity`(WCSession)** 다. App Group 은 같은 기기 안에서만 통한다. Flutter 쪽은 플랫폼 채널이나 `watch_connectivity` 계열 패키지를 서비스 추상화 뒤에 둔다(M4·M5 규칙과 동일).
- **워치페이스 컴플리케이션은 WidgetKit** — iOS 위젯과 같은 프레임워크라 코드·개념이 이어진다.
- **실기기 테스트에는 유료 Apple Developer Program 이 필요**하다. 워치 앱은 iOS 앱 번들 안에 실려 배포된다.
- 안드로이드 Wear OS 는 완전히 별개 작업(Kotlin/Compose for Wear). 같은 마일스톤에 묶지 않는다.

## 단계 설계

### 1단계 — 보기 전용 (안전, 먼저 한다)

워치는 **계산하지 않는다.** 폰이 만든 표시 문자열을 받아 그대로 그린다. 지금 홈 위젯과 완전히 같은 규약이라 `domain/widget_payload.dart`의 `buildWidgetPayload` 를 그대로 재사용한다.

- 워치 앱 화면: 이번 달 총 공수 / 근무일 / 실수령(또는 세전)
- 워치페이스 컴플리케이션: 총 공수 한 줄
- 전달: 폰이 값이 바뀔 때 `updateApplicationContext` 로 최신 상태만 덮어쓴다(큐 없이 최신값 1개)
- **데이터 위험 0** — 워치는 읽기만 한다

### 2단계 — 손목에서 기록 (큐 기반, 유실 방지가 핵심)

워치에서 프리셋 버튼 1탭으로 오늘 공수를 넣는다. 여기서 데이터 유실 원칙(절대 원칙 4)이 걸리므로 규칙을 못 박는다.

- **워치는 DB 를 갖지 않는다.** "폰에 보낼 기록 큐"만 갖는다.
- 전달은 `transferUserInfo` — 폰 앱이 꺼져 있어도 iOS 가 **보장 전달**한다(재부팅·통신 두절 뒤에도 큐가 살아 있다).
- 기록마다 **uid(UUIDv4)** 를 워치에서 만들어 붙인다. 폰은 기존 백업 병합과 **같은 upsert 경로**로 저장한다 — 두 번 전달돼도 중복 생성되지 않는다.
- 워치 화면에 **"폰에 아직 안 넘어간 기록 n건"** 을 항상 표시한다. 사용자가 모르는 사이 사라지는 경우를 만들지 않는다. n>0 이면 워치에서 큐 내용을 볼 수 있게 한다.
- **워치에서 삭제·수정은 지원하지 않는다.** soft delete·실행 취소는 폰에서만. 양방향 편집은 충돌 규칙을 새로 만들어야 하고, 그 복잡도는 이 앱이 감당할 가치가 없다.
- 업체는 **마지막에 쓴 업체**로 자동 지정(폰의 `last_site_id` 를 1단계 컨텍스트에 실어 보낸다). 워치에서 업체를 고르게 만들면 탭이 늘어 취지가 죽는다.

### 3단계 — 선택 사항

- Digital Crown 으로 0.05 단위 공수 조절(자체 키패드 원칙의 워치판)
- 오늘 이미 넣은 기록 요약 보기
- 상시 표시(Always-On) 대응

## 프로 정책 (오너 결정 필요)

지금 위젯은 프로 전용이다. 워치를 넣는다면 선택지는 셋이다.

| 안 | 내용 | 근거 |
|---|---|---|
| A | 위젯 무료 + 워치 프로 | 위젯으로 갈아타게 만들고, 손목 기록이라는 "더 쓰는 사람"에게 과금 |
| B | 둘 다 프로 | 하드웨어 기능 묶음이 곧 프로의 정체성 |
| C | 둘 다 무료, PDF 증빙만 프로 | 증빙이 필요한 절박한 순간에만 과금 |

## 마일스톤 위치

v1(M1~M6)은 출시 준비가 끝났다. 애플워치는 **v1.1(M7)** 로 분리한다. v1 을 먼저 내고 실사용 반응을 본 뒤 붙이는 편이 안전하다. 유료 개발자 프로그램 가입이 선행 조건이다.

## 재사용 가능한 것 (이미 있음)

- `domain/widget_payload.dart` — 표시 문자열 생성(순수 함수). 워치도 그대로 쓴다
- `domain/uid.dart` — uid 생성 규약
- `data/repositories/work_entry_repository.dart` — uid 부여·검증을 한곳에 모은 저장 진입점
- `tool/ios_add_widget_target.rb` — Xcode 타깃을 스크립트로 추가하는 패턴(워치 타깃도 같은 방식)
- `services/` 추상화 패턴 — 플러그인을 직접 부르지 않고 가짜로 테스트
