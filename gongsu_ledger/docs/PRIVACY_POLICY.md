# 공수장부 개인정보처리방침
시행일: 2026년 9월 2일

1. 수집하는 개인정보: 없습니다.
공수장부는 회원가입·로그인이 없고, 사용자가 입력한 공수·업체·단가·부가항목·메모는 사용자의 기기 안에만 저장됩니다. 개발자는 이 데이터를 볼 수 없습니다.

2. 서버 전송·외부 전송: 없습니다.
앱은 인터넷 연결 없이 동작하며, 분석·광고·추적 도구(SDK)를 넣지 않았습니다.

3. 백업 파일
"백업 / 복원" 메뉴에서 사용자가 직접 내보낼 때만 백업 텍스트·파일이 만들어지고, 사용자가 고른 곳(메신저, 파일 앱 등)으로만 이동합니다. 앱이 스스로 어디론가 보내지 않습니다.

4. 결제
프로(일회성 구매) 결제는 Apple App Store 또는 Google Play가 처리합니다. 앱은 카드·계좌 등 결제 정보를 받지 않으며, 구매 여부만 기기에 저장합니다.

5. 홈 위젯
이번 달 공수·금액 표시 문자열을 기기 안 앱 전용 저장 공간에 저장해 위젯이 읽습니다. 외부로 전송되지 않습니다.

6. 권한
별도의 권한을 요구하지 않습니다. 파일 저장·공유는 사용자가 버튼을 누를 때 운영체제의 공유 창을 통해서만 이루어집니다.

7. 데이터 삭제
앱을 삭제하면 기기 안의 모든 기록이 함께 삭제됩니다(스토어의 구매 기록은 스토어 정책을 따릅니다).

8. 방침 변경
방침이 바뀌면 앱 업데이트와 함께 이 화면에 새 시행일을 표시합니다.

9. 문의
스토어 앱 정보에 표시된 개발자 연락처로 문의해 주세요.
