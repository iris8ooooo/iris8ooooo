# 공수장부 실행 가이드 (비개발자용, Mac 기준)

이 문서는 개발 지식 없이 Mac에서 공수장부 앱을 직접 실행해 보는 방법입니다.
Windows PC + 갤럭시는 `RUN_GUIDE_WINDOWS.md` 를 보세요 (체크리스트는 이 문서의 것을 같이 씁니다).
처음 한 번만 1~5단계를 하면, 이후에는 6단계부터만 반복하면 됩니다.

---

## 1. Xcode 설치 (약 30분~1시간, 처음 한 번만)

1. Mac의 **App Store**를 열고 **Xcode**를 검색해 설치합니다 (무료, 용량이 커서 오래 걸립니다).
2. 설치가 끝나면 Xcode를 한 번 실행하고, 약관 동의와 추가 구성 요소 설치를 진행합니다.
3. Xcode는 닫아도 됩니다.

## 2. 터미널 열기

- **Spotlight**(화면 오른쪽 위 돋보기 아이콘 또는 ⌘+스페이스)에서 `터미널`을 검색해 실행합니다.
- 아래의 회색 상자 안 명령어들은 터미널에 **한 줄씩 복사해 붙여넣고 엔터**를 치면 됩니다.

## 3. Flutter 설치 (처음 한 번만)

```bash
mkdir -p ~/development
cd ~/development
curl -o flutter.zip https://storage.googleapis.com/flutter_infra_release/releases/stable/macos/flutter_macos_arm64_3.47.2-stable.zip
unzip -q flutter.zip
echo 'export PATH="$HOME/development/flutter/bin:$PATH"' >> ~/.zprofile
```

> 참고: 2020년 이전의 인텔 Mac이라면 주소의 `arm64_`를 지운
> `flutter_macos_3.47.2-stable.zip` 을 받으세요.
> Mac 종류는 화면 왼쪽 위  → "이 Mac에 관하여"에서 칩이
> "Apple M1/M2/M3/M4"면 arm64가 맞습니다.

터미널을 완전히 종료했다가 다시 열고, 설치를 확인합니다:

```bash
flutter doctor
```

초록 체크가 몇 개 보이면 성공입니다. iOS 줄에 CocoaPods 관련 빨간 X가 있으면:

```bash
sudo gem install cocoapods
```

(암호를 물으면 Mac 로그인 암호를 입력하세요. 입력해도 화면에 표시되지 않는 게 정상입니다.)

## 4. 앱 코드 내려받기 (처음 한 번만)

```bash
cd ~/development
git clone https://github.com/iris8ooooo/iris8ooooo.git gongsu-app
cd gongsu-app
git checkout claude/worker-timesheet-flutter-app-6pltoc
```

## 5. 앱 준비

```bash
cd ~/development/gongsu-app/gongsu_ledger
flutter pub get
```

## 6. 아이폰 시뮬레이터로 실행 (가장 쉬움)

```bash
open -a Simulator
```

가상 아이폰 화면이 뜨면 (1분쯤 걸릴 수 있음):

```bash
cd ~/development/gongsu-app/gongsu_ledger
flutter run
```

첫 실행은 몇 분 걸립니다. 시뮬레이터에 **공수장부 달력**이 뜨면 성공입니다.
끝낼 때는 터미널에서 `q`를 누르세요.

## 7. (선택) 실제 아이폰으로 실행

실기기는 애플 서명 절차가 필요해 한 단계가 더 있습니다:

1. 아이폰을 케이블로 Mac에 연결하고, 아이폰에서 "이 컴퓨터를 신뢰"를 누릅니다.
2. 아이폰 설정 → 개인정보 보호 및 보안 → **개발자 모드**를 켜고 재부팅합니다.
3. 터미널에서:
   ```bash
   open ~/development/gongsu-app/gongsu_ledger/ios/Runner.xcworkspace
   ```
4. Xcode가 열리면 왼쪽에서 **Runner**를 클릭 → 가운데 **Signing & Capabilities** 탭 →
   **Team**에서 "Add an Account..."로 본인 Apple ID를 추가하고 선택합니다.
5. 다시 터미널에서 `flutter run` — 기기 목록에서 본인 아이폰을 고릅니다.
6. 아이폰에서 "신뢰하지 않는 개발자" 경고가 나오면:
   설정 → 일반 → VPN 및 기기 관리 → 본인 Apple ID → 신뢰.

## 8. 나중에 새 버전 받기

작업이 진행되어 새 코드가 올라오면:

```bash
cd ~/development/gongsu-app
git pull
cd gongsu_ledger
flutter pub get
flutter run
```

- [ ] 메뉴(⋮) → **백업/복원**에서 "전체 데이터 복사" → 메모장에 붙여넣기 → "병합 복원"으로 되돌리기

- [ ] **비행기 모드에서도 전부 동작한다**
- [ ] Mac 시스템 설정을 다크모드로 바꾸면 앱도 어두운 테마로 보인다 (시뮬레이터 반영)

## M2에서 확인해 볼 것 (업체·단가·부가항목)

- [ ] 메뉴(⋮) → **업체(현장) 관리** → "업체 추가": 이름·색·1공수 단가(예: 150000) 입력 후 저장
- [ ] 날짜 탭 → 시트 맨 위에 **업체 칩**이 생겼다. 업체를 고르고 프리셋 탭 → 달력 점이 **업체 색**으로 표시
- [ ] 월 합계 카드에 **예상 수입(세전)** 줄이 나타난다 (1공수 × 150,000원)
- [ ] 다른 날을 열면 **방금 고른 업체가 이미 선택**되어 있다 (매번 고를 필요 없음)
- [ ] 업체 관리 → 업체 탭 → **단가 변경**: 적용 시작일을 다음 달 1일로, 금액 165000 → 저장
  - 이번 달 기록의 예상 수입은 **그대로**(150,000원 기준)이고, 다음 달에 입력하면 165,000원 기준으로 계산된다 ← 핵심
- [ ] 기록 행을 탭 → **"이 날만 단가 설정"** 200000 → 그 날만 200,000원으로 계산, 업체 단가 이력은 그대로
- [ ] 시트의 **부가항목 → 추가**: "식비" 10000 가산 → 예상 수입에 +10,000원. "안전용품비" 공제 → −
- [ ] 부가항목 삭제 → "실행 취소" 가능
- [ ] 백업/복원 → "전체 데이터 복사" → 병합 복원해도 업체·단가·부가항목이 유지된다
- [ ] 업체를 삭제(보관)해도 과거 기록의 업체명·색과 예상 수입은 그대로다
- [ ] 이전(M1) 버전에서 쌓은 기록이 있다면 **앱 업데이트 후에도 전부 그대로** 보인다 (v1→v2 마이그레이션)

문제가 생기면 터미널에 보이는 빨간 글씨를 복사해서 Claude에게 붙여넣어 주세요.

## M3에서 확인해 볼 것 (세금·정산·통계·공휴일)

- [ ] 메뉴(⋮) → **업체(현장) 관리** → 업체 탭 → **세금 방식**에서 "3.3% 원천징수" 선택 → 저장
  - 달력 월 카드에 **실수령 (세후)** 줄이 생기고, 세전보다 3.3%만큼 적다 (예: 300,000원 → 290,100원)
- [ ] 세금 방식을 **4대보험**으로 바꾸면 "일용근로소득세 함께 계산" 스위치와 "월 8일 이상 근무 / 항상 적용" 선택이 보인다
  - 같은 업체에서 8일 이상 기록한 달에만 국민연금·건강보험이 빠진다 (7일 이하면 고용보험·일용소득세만)
- [ ] 메뉴 → **정산 (기간 지정)**: "이번 달 / 지난달" 칩, 시작일·종료일 직접 선택. 업체별 카드에 소득세·지방소득세·국민연금·건강보험·장기요양·고용보험이 항목별로 보인다
  - 오른쪽 위 🔁 아이콘에서 **마감 주기 시작일**을 21로 바꾸면 "마감 주기 (21일~)" 칩이 생기고, 전월 21일 ~ 당월 20일로 정산된다
- [ ] 메뉴 → **통계**: 연도 화살표, 월별 막대(공수)와 월 실수령, 연간 공수·세전·실수령, 업체별 합산
- [ ] 메뉴 → **세금 · 요율 설정**: 2026년 요율(국민연금 4.75%, 건강 3.595%, 장기요양 12.95%, 고용 0.9% …)이 보이고, 항목을 탭해 고칠 수 있다. 고친 항목엔 연필 표시, 오른쪽 위 **초기화**로 되돌린다
  - **끝전 처리**를 "원 단위 그대로"로 바꾸면 실수령이 몇 원 단위로 달라진다 (기본은 10원 미만 절사)
- [ ] 시트에서 **부가항목 → 가산**에 "세금 계산에 포함 (과세)" 스위치가 있다. 켜고 넣은 금액은 세금 계산에 들어간다
- [ ] 달력에서 **공휴일**(예: 10월 3일 개천절, 10월 9일 한글날)이 일요일처럼 빨간색이고, 그 날짜를 탭하면 시트 제목에 "· 개천절"처럼 공휴일 이름이 붙는다
- [ ] 이전(M2) 기록·업체·단가가 앱 업데이트 후에도 그대로 (v2→v3 마이그레이션). 업체의 세금 방식은 "공제 없음"으로 시작한다

## M5에서 확인해 볼 것 (홈 위젯)

이번 코드에는 아이폰 위젯용 Xcode 설정이 이미 들어 있어요 (`ios/GongsuWidget` 폴더와 `Runner.xcodeproj`). Xcode에서 따로 만들 것은 없습니다. 새 코드를 받은 뒤(8번) 터미널에서 `flutter pub get` → `flutter run`으로 시뮬레이터에 앱을 한 번 띄우세요.

- [ ] 시뮬레이터 홈 화면(앱 밖)에서 빈 곳을 길게 누르기 → 왼쪽 위 **+** → 검색창에 "공수장부" → **이번 달 공수** 위젯 → **위젯 추가**
- [ ] 위젯에 "9월 공수 / 총 공수 숫자 / 근무 n일"이 보이고, 업체에 단가가 있으면 아래에 **실수령(또는 세전) 금액**이 보인다
- [ ] 앱에서 공수를 넣거나 지우면 위젯 숫자가 곧바로(몇 초 안) 바뀐다. 1.8공수는 위젯에도 1.8로 나온다
- [ ] 위젯을 누르면 앱이 열린다
- [ ] 시뮬레이터를 다크모드로 바꾸면(설정 → 디스플레이 및 밝기) 위젯 배경도 어두워진다
- [ ] 단가가 하나도 없으면 금액 줄이 없고, 업체 관리에서 단가를 넣으면 금액 줄이 생긴다

**실행이 "Signing" 또는 "App Groups" 오류로 멈추면**: `ios/Runner.xcworkspace`를 Xcode로 열기 → 왼쪽 맨 위 **Runner** 클릭 → 가운데 TARGETS에서 **Runner** → **Signing & Capabilities** 탭 → Team을 본인 Apple ID로 선택. 같은 화면에서 TARGETS의 **GongsuWidget**도 같은 Team으로 선택한 뒤 다시 `flutter run`. 시뮬레이터는 무료 Apple ID로 충분합니다. 실제 아이폰에서는 위젯의 App Groups 기능 때문에 유료 개발자 계정이 필요할 수 있어요 — M6 출시 준비 때 함께 처리합니다.

**갤럭시(안드로이드)에서 보려면**: Windows PC에 Flutter를 설치하고 USB로 연결해 `flutter run` (이 가이드는 Mac 기준이라, 원하시면 Windows용 가이드를 따로 만들어 드립니다). 홈 화면 길게 누르기 → **위젯** → **공수장부** → "이번 달 공수"(2×2)를 끌어다 놓기.

## M6에서 확인해 볼 것 (온보딩 · 설정 · 프로 · 출시 준비)

- [ ] 시뮬레이터에서 앱을 지운 뒤(홈에서 길게 눌러 삭제) 다시 `flutter run` → 첫 화면이 **직군 선택**(건설 / 조선소 / 직접 만들기)이다. 조선소를 고르면 달력의 입력 버튼이 A(0.9)/B(1.0)/E잔업/야간/반공/휴무로 바뀐다
- [ ] 메뉴(⋮) → **설정**: 글씨 크기 "아주 크게"로 바꾸면 모든 화면 글씨가 커지고 깨지는 곳이 없다. 화면 모드 "어둡게", 주 시작 요일 "월요일"(달력 첫 열이 월요일로)
- [ ] 설정 → **직군 프리셋 다시 고르기**: 이름을 고친 프리셋은 그대로 남고 안 고친 기본 버튼만 바뀐다
- [ ] 앱 이름이 홈 화면에 **공수장부**로, 아이콘이 파란 달력 카드로 보인다
- [ ] **무료 제한**: 업체를 3개 만든 뒤 하나 더 추가하면 **프로 안내 화면**이 뜬다. 정산의 PDF 버튼, 설정의 테마 색도 같은 안내가 뜬다. 위젯은 "프로 전용" 문구를 보여준다
- [ ] 프로 화면에서 "프로 구매하기"를 누르면 시뮬레이터에서는 **"스토어를 사용할 수 없어요"** 안내가 뜬다 — 정상입니다. 실제 결제 테스트는 RELEASE_GUIDE 의 TestFlight 샌드박스 / Play 라이선스 테스터로 합니다
